# Code de conduite

[English](CODE_OF_CONDUCT.md) · **Français**

CineVault suit le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/). Toute personne qui participe à ce projet, dans les tickets, les pull requests, les discussions ou n'importe quel autre de ses espaces, est tenue de le respecter.

En bref : soyez accueillant, respectez les points de vue et les expériences différents, acceptez avec élégance les critiques constructives et concentrez-vous sur ce qui est le mieux pour la communauté. Le harcèlement, les insultes et les attaques personnelles ne sont pas tolérés.

## Signalement

Si vous subissez ou êtes témoin d'un comportement inacceptable, contactez le mainteneur en privé via GitHub : [@imtheyoyo](https://github.com/imtheyoyo). Pour les problèmes qui ne doivent pas être discutés publiquement, vous pouvez aussi ouvrir un avis de sécurité privé (voir [SECURITY.md](SECURITY.fr.md)) et l'indiquer comme un signalement de conduite. Tous les signalements sont examinés rapidement et traités de façon confidentielle.

Le mainteneur peut supprimer, modifier ou refuser les commentaires, commits, code, tickets et autres contributions qui ne respectent pas ce code de conduite, et peut bloquer des contributeurs pour un comportement qu'il juge inapproprié, comme décrit dans les directives d'application du Contributor Covenant.
